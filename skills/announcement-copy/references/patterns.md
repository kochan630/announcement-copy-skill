# 告知文の組み立て方

読者が参加・購入を判断できるよう、実際の提供内容と条件を具体的に伝える。以下は構成の指針であり、成約率や成果を保証するものではない。

## 使える工夫

| 使える工夫 | セミナー・コンテンツ告知への使い方 | 根拠が必要な点 |
|---|---|---|
| 読者の困りごとを具体的な作業として示す | 「AIを使いたい」を、日常の作業や迷っている場面へ近づける | 読者像は依頼・既存顧客の言葉から取る。想像なら例と明示する |
| 初心者が進める理由を説明する | ガイド・操作手順・質問対応の範囲を近くに書く | 本当に提供する支援だけを書く |
| 学んだ内容を自分の作業で試す流れを示す | 実習の題材、つくるもの、翌日からの利用場面を説明する | 成果物の完成を保証するか、取り組むだけかを区別する |
| 同じ指示や作業を繰り返す手間に触れる | テンプレートや再利用できる手順の用途を説明する | 自動化の範囲と、利用者が確認する作業を曖昧にしない |
| 時間や対象を見出しに入れる | 確定した所要時間、対象者、扱う範囲を使う | 所要時間を成果達成までの時間にすり替えない |
| 見本・支援・実績を示す | 実際の画面、作成例、確認済みの経験を使う | サンプルを実績と呼ばない。紹介報酬や特典のあるレビューも効果の証明にしない |

## セミナーでの適用例

元の見出し例：セカンドブレインを活用した業務改善方法の実践セミナー。

見出し案：ためたメモやアイデアを、仕事に活かす4時間。

説明の案：自分の知識を整理する仕組みをつくり、身近な仕事の効率化・自動化に挑戦します。

この案を使うには「4時間」「知識の整理」「業務の効率化・自動化への挑戦」が実際の内容と一致している必要がある。「誰でも完全自動化」「必ず時短」といった約束は含めない。

コンテンツ販売では、所要時間よりも、扱う場面・収録物・必要な準備・利用条件が判断材料になる場合がある。セミナー用の構成をそのまま当てはめない。
